# 최종 보고서 구성안

## 1. 프로젝트 개요

- 프로젝트 목적
- 분석 대상과 범위
- 교육용/분석용 프로젝트임을 명시
- 실제 피해 파일 복구 보장 아님

## 2. Rhysida 암호화 구조

- PRNG 기반 AES key/IV 생성 구조
- AES-CTR 파일 본문 암호화
- RSA-4096 기반 key/IV 보호
- footer 또는 metadata 영역의 역할

## 3. 정적 분석 결과

- 파일 탐색 흐름

- 간헐적 암호화 구조
- 파일 I/O 흐름
- footer append 흐름
- 정적 분석 기반 IOC

## 4. 동적 분석 결과 및 모니터링 계획

- 격리 환경 구성
- 파일 생성/수정 관찰 항목

- 네트워크 행위 여부
- 확인된 내용과 미확인 내용 구분
