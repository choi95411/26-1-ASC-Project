# [제 6차 프로젝트 진행 보고서] Rhysida 랜섬웨어 복호화 분석 프로젝트

- **팀원:** (팀장) 20221525_최민혁, (팀원) 20251739_이지원, 20243303_최지우, 20261619_안시후
- **활동 기간:** 2026. 07. 22. ~ 2026. 08. 04. (2주)

## 팀 전체 진행 현황

- **이번 회차 목표:** 5차에서 구현한 안전한 dummy 파일 기반 암호화·복호화 파이프라인을 최종 산출물 수준으로 보완하고, 성공·실패 테스트 결과와 한계 조건을 정리하여 최종 보고서 및 발표 자료의 기반을 마련한다.
- **현재 진행률:** 85% (전체 일정 대비)
- **주요 달성 사항:**
  - `safe_test_encrypt.py`, `rhysida_file_parser.py`, `recovery_demo.py`로 이어지는 암호화 → 파일 구조 분석 → AES-CTR 복호화 → SHA-256 검증 흐름을 재검증하였다.
  - 정상 입력 1건과 예외·변조 입력 5건을 통해 파이프라인의 성공 조건과 오류 처리 동작을 확인하였다.
  - 원본 SHA-256과 복구 파일 SHA-256의 일치 여부를 최종 복구 성공 기준으로 정리하였다.
  - 실행 방법, 테스트 벡터 기대 결과, 프로젝트 적용 범위와 한계를 문서에 반영하였다.
  - 최종 보고서 구성안과 발표 체크리스트를 작성하여 최종 제출 단계의 작업 항목을 정리하였다.

## 이슈 및 해결 방안

- **문제 상황:** 현재 구현은 프로젝트에서 직접 만든 dummy 파일과 테스트용 footer 구조를 대상으로 하므로 실제 Rhysida 피해 파일의 복구를 보장할 수 없다. 또한 잘못된 key가 같은 길이로 입력되면 복호화 명령 자체는 종료될 수 있어, 성공 여부를 별도의 무결성 검증 결과로 판단해야 한다.
- **해결 현황:** 실제 악성 샘플 실행 없이 단일 dummy 파일을 대상으로 하고 원본을 덮어쓰지 않는 안전한 실행 범위를 유지하였다. 복호화 결과는 SHA-256 비교의 `verified` 값으로 판정하며, 예외 처리 결과와 프로젝트의 적용 한계를 보고서 및 발표 자료에 명시하도록 정리하였다.
